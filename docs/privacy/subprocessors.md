# Subprocessors

Keep this list aligned with production contracts and the privacy notice.

| Provider | Purpose | Data | Location / safeguards |
| --- | --- | --- | --- |
| Supabase | Authentication, database, files and Edge Functions | Account and business data | Configured project region; DPA and applicable transfer safeguards |
| Cloudflare | Website delivery, CDN and security | IP address, request metadata | DPA and applicable transfer safeguards |
| Stripe | Subscription billing | Company, billing and payment metadata | DPA and applicable transfer safeguards |
| Google | Fonts and optional Gmail connection | Request metadata; mailbox data only when enabled | User-authorised connection and applicable safeguards |
| Microsoft | Optional Microsoft 365 connection | Mailbox data only when enabled | User-authorised connection and applicable safeguards |
| Customer-selected IMAP provider | Optional mailbox connection | Mailbox credentials and messages | Depends on provider selected by the customer |
